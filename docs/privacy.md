# Privacy and authorization model

## 默认行为

第一版只做只读审计和推荐。它不自动安装软件、不写入 PATH、不修改 Agent 配置、不登录第三方服务，也不上传文件正文。

## 可扫描信息

在用户明确授权后，可以检查：

- 当前工作目录和有限深度的文件名/扩展名；
- package.json、requirements.txt 等项目依赖文件的名称，不读取密钥字段；
- 用户明确指定的命令的版本或 help 输出；
- 某些工具是否存在及其版本证据。

## 不扫描信息

- 文件正文、聊天内容和邮件正文；
- API Key、Cookie、Token、OAuth refresh token；
- 未授权目录；
- 云端服务的历史使用记录，除非用户显式连接并确认对应 API。

“之前使用过哪些 Agent”不能凭空获得。第一版只能根据当前可见的本地痕迹、用户主动提供的历史导出或用户回答来推断，并把推断标注为推断。

## 推荐前的检查

每个候选需要说明来源状态、需要的权限、数据去向、验证方法和卸载/断开方式。用户未确认前只展示官方链接和命令，不执行安装。
