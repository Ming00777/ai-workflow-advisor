# Source register

本表记录第一版目录的来源和判断。验证日期：2026-09-15。

| 条目 | 来源 | 判断 |
|---|---|---|
| 飞书 / Lark CLI | [larksuite/cli](https://github.com/larksuite/cli) | 飞书团队维护的官方 GitHub 仓库；覆盖文档、表格、日历、邮件、任务等能力。 |
| Kimi Code CLI | [Kimi Code 官方文档](https://www.kimi.com/code/docs/) | 官方文档明确说明 CLI 可在终端阅读和编辑文件、执行命令并进行网页搜索。 |
| CodeBuddy CLI | [CodeBuddy CLI reference](https://staging-codebuddy.tencent.com/docs/cli/reference) | 官方文档入口；发布前需要再次确认稳定文档域名。 |
| 百度网盘 CLI | [wxnacy/bdpan-cli](https://github.com/wxnacy/bdpan-cli) | 社区项目，不能称为百度官方 CLI；使用前审阅源码、凭证保存方式和许可证。 |
| 扣子 Agent | [扣子 Agent 文档](https://docs.coze.cn/cozespace_coze_agent) | 官方文档说明 Agent 可通过 Skills、MCP 和插件扩展。 |
| 扣子文档 MCP | [扣子 MCP 文档](https://docs.coze.cn/mcp) | 官方文档公开了连接方式、端点和权限/第三方数据提示。 |
| 腾讯 WorkBuddy | [腾讯云 WorkBuddy](https://cloud.tencent.com/product/workbuddy) | 官方产品入口；作为 Agent 产品收录，不编造独立 CLI 或 MCP 安装命令。 |

“排名靠前”在本项目中不直接等同于 GitHub stars。优先级综合官方维护、国内用户可用性、文档可验证性、权限成本和场景覆盖；目录会保留社区项目和待核验候选的状态。
