# Recommendation demo

## User request

我主要处理飞书文档、Excel 和会议纪要，希望减少本地文件和云端文档之间的重复整理。先只读分析，不要安装。

## Observed facts

- 用户明确提到飞书、Excel 和会议纪要。
- 用户明确要求只读分析。
- 未检查文件正文、凭证或聊天记录。

## Recommendation

1. 飞书 / Lark CLI：如果需要在本地 Markdown 与飞书文档、表格之间同步，可优先阅读官方仓库并确认应用权限。
2. 扣子文档 MCP：如果用户主要需要检索扣子产品文档，可使用官方 MCP；如果要操作自己的企业资料，需要另外确认数据源和权限。
3. 文档处理能力：先选择当前 Agent 已支持的文档/PDF工具，使用一份匿名样例验证，再决定是否增加云端连接。

## What the advisor must not say

不能声称已经知道用户过去的 Agent 使用次数，不能直接读取飞书内容，不能把社区百度网盘 CLI 说成百度官方产品，也不能在用户没有授权时执行安装。
